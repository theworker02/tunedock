# tunedock

Tune identifiers and dock tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tunedock/

## Install / run

```bash
git clone https://github.com/theworker02/tunedock.git
cd tunedock
node src/cli.js
node --test
```
